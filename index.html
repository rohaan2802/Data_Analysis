Overview

A practical collection for understanding the complete database analysis workflow.

This project starts with conceptual ER modeling, then turns the Brazilian Olist e-commerce data into a relational SQL Server database. Queries examine delivery delays, customer purchasing patterns, product demand and seller logistics. Selected results are preserved as CSV exports, charts and labelled screenshots.

The website is a browsable coursework companion. SQL runs in SQL Server / SSMS; the browser displays the documentation and saved results, rather than querying a live database.

Reproduce the Analysis

A readable setup path, with the original coursework limitations kept visible.

01 · Prepare

SQL Server & SSMS

Use SQL Server with permissions to create a database and import CSV files. This coursework uses T-SQL, not MySQL or browser-based SQL.

02 · Configure

Set your CSV paths

Replace every hard-coded BULK INSERT path in the submitted script. The SQL Server service account must be able to read your dataset folder.

03 · Load

Follow the parent-first order

The submitted DDL needs reordering before execution. Create parent tables before foreign-key children; deduplicate geolocation before loading dependants.

04 · Analyze

Run & compare

Execute the four Task 2 analysis blocks, compare the saved outputs, and run Northwind separately if you want additional practice.

Clone the repository
git clone https://github.com/rohaan2802/Data_Analysis.git

Important source limitations

  • Keep the catery spelling consistent with the submitted schema.
  • Order H uses SUM(order_item_id), not a literal item count; review it before reusing the result.
  • Cancellation rates can look extreme for sellers with very small samples.
  • Dataset copies and ZIP archives make a full clone large. You can browse the documentation without downloading them.
