# GitHub Pages and repository About

Website: https://rohaan2802.github.io/Data_Analysis/

## Preview

From the repository root, run `python -m http.server 8000` and open `http://localhost:8000/`.
Opening `index.html` directly also works for the static page and its local screenshots.

## GitHub Pages setup

1. Review and push the website changes to this repository's `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and Save.
4. Wait for GitHub Pages to finish its deployment. The website URL will be:
   https://rohaan2802.github.io/Data_Analysis/
5. Only after deployment succeeds, place that URL in the repository's **About → Website** field.

No Node build, API key, database connection or hosting service is required. `.nojekyll` keeps deployment static. Original large datasets are linked on GitHub rather than loaded by the webpage.
