# Start here

Open **index.html** in your browser to preview the website.

For a local server, open a terminal in this folder and run:

    python -m http.server 8000

Then open http://localhost:8000/ .

The page is prepared locally only. No changes have been pushed to GitHub and no site has been deployed.
